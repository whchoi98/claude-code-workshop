CLAUDE CODE DEEP DIVE WORKSHOP

Claude Code Deep Dive Workshop

AWS이론 + 핸즈온 + 캡스톤5 Chapters + Capstone

Claude Code는 개인의 생산성 도구를 넘어, 팀의 개발 프로세스를 구성하는 핵심 요소로 진화하고 있습니다. 이 단계에서 요구되는 것은 기능의 나열이 아니라 운영의 설계입니다. 본 워크샵은 권한을 어디까지 허용할 것인가, 사용량과 비용을 어떤 지표로 관측할 것인가, 검증된 방식을 어떻게 팀 전체에 배포할 것인가라는 세 가지 질문을 이틀에 걸쳐 순서대로 다룹니다.

Day 1은 개인 역량으로 첫 완결에 도달하는 여정입니다. 아키텍처 소개와 설치, 헤드리스 실행(Chapter 1)으로 기초를 다지고, 역할별 서브에이전트(Chapter 2)로 작업을 병렬화하며, managed-settings 기반의 정책 통제와 관측(Chapter 3)으로 운영의 인사이트를 확보합니다. 오후의 캡스톤 라운드 1에서는 게임, 미술관, 지진 워치 세 트랙 중 하나를 선택해, 설계부터 배포과 공유까지 완결의 전 과정을 직접 경험합니다.

Day 2는 팀 플랫폼화와 AI 통합에 집중합니다. 훅과 스킬을 팀의 공용 자산으로 승격하고(Chapter 4), Claude Code를 파이프라인의 구성 요소로 전환합니다(Chapter 5). 캡스톤 라운드 2에서 Bedrock 분석이 결합된 서비스(증시, 유튜브, 뉴스룸 렌즈 중 택 1)를 하네스 엔지니어링까지 더해 완주합니다. 마지막으로 실습에서 사용한 토큰을 소재 삼아 모델 라우팅과 메터링을 정리하며 이틀의 과정을 마무리합니다. 이론과 실습을 균형 있게 배치하였으며, 전 과정은 참가 조직의 환경과 과제에 맞추어 설계된 맞춤형 워크샵입니다.

교육 환경

EC2 + code-server / 브라우저 접속

개인 노트북 설정 차이로 실습이 막히지 않도록, 모든 참가자에게 동일한 EC2 인스턴스를 제공합니다. 별도 설치나 SSH 없이 브라우저로 code-server에 접속하면 사전에 설치된 Claude Code가 바로 준비되어 있습니다.

01
사전 준비물
노트북 + 브라우저

최신 브라우저만 있으면 충분합니다. 로컬에 아무것도 설치하지 않아도 되며, 접속 주소와 계정 정보는 현장에서 배부합니다.

02
접속 방식
브라우저 → code-server

1인 1인스턴스의 EC2에 브라우저로 접속합니다. VS Code와 같은 화면에서 편집기와 통합 터미널을 함께 쓰므로, 코드와 claude 세션을 나란히 두고 진행할 수 있습니다.

03
Claude Code

04

Claude Enterprise 기반과 Amazon Bedrock 기반 중 원하는 경로를 골라 접속합니다. Chapter 1에서 두 경로를 나란히 비교하고, 조직 단위 통제와 비용 관측은 Chapter 3에서 다룹니다.
