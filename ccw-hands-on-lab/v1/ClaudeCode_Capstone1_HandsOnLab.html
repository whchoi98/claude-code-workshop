관찰 포인트 점프의 손맛은 상수 셋의 균형입니다: 중력(초당 가속), 점프 초속도, 코요테 타임. 붕 뜬다 싶으면 중력을 키우고, 발이 미끄러지면 마찰을 넣어 달라고 말로 주문하세요. 수치를 직접 고치는 게 아니라 느낌을 말하면 Claude가 수치를 찾는 것, 그게 이 랩의 연습입니다.
개념 짚기 (Level 200), dt와 손맛의 물리 점프 높이는 대략 JUMP_V² / (2G)에서 나옵니다. JUMP_V만 키우면 붕 뜨고, G를 함께 키우면 "높이 뜨되 시원하게 떨어지는" 손맛이 됩니다. 그리고 모든 이동에 dt를 곱하는 이유: 120Hz 모니터에서도 60Hz와 같은 점프가 나와야 하기 때문입니다. 코요테 타임(발판을 떠난 직후 0.1초의 관용)과 점프 버퍼(착지 직전 입력의 예약)는 "억울한 죽음"을 줄이는 플랫포머의 표준 배려입니다.
막힐 때 열어보기, 물리 핵심 힌트
물리 상수와 점프 (참고 조각)
const G = 1500, JUMP_V = -420, MOVE = 160;   // px/s 기준
let coyote = 0, jumpBuf = 0;
function step(dt) {
  coyote = onGround ? 0.1 : Math.max(0, coyote - dt);
  jumpBuf = keys.jump ? 0.1 : Math.max(0, jumpBuf - dt);
  if (jumpBuf > 0 && coyote > 0) { vy = JUMP_V; coyote = 0; jumpBuf = 0; }
  vy += G * dt;
  x += vx * dt;  y += vy * dt;   // 이후 AABB 충돌 해소
}

개념 짚기 (Level 200), 타일 충돌의 축 분리 충돌 해소를 X축 이동 후 한 번, Y축 이동 후 한 번, 따로 하는 이유가 있습니다. 한 번에 대각선으로 밀어 넣고 해소하면 벽 모서리에서 어느 축으로 밀어낼지 애매해져 끼임과 떨림이 생깁니다. "X로 걷다 벽에 막히고, Y로 떨어지다 바닥에 선다"를 분리하면 각 축의 답이 자명해집니다. 레벨이 타일 그리드인 것도 같은 이유, 충돌 후보를 내 주변 몇 칸으로 즉시 좁힐 수 있습니다.
