플러그인, 팀의 하네스를 배포하는 단위

워크샵 사용 플러그인 3종과 설치, 운영 요령

스킬 하나를 복사해 나르던 시대에서, 스킬과 훅과 에이전트를 한 묶음으로 설치하는 시대로 넘어가는 장치가 플러그인입니다. 마켓 등록 → 설치 → 세션 재시작, 세 박자면 끝납니다.

플러그인이란

스킬, 커맨드, 서브에이전트, 훅, MCP 서버를 하나로 묶어 설치하는 배포 단위입니다. Chapter 4에서 만든 킷의 완성형이 곧 플러그인입니다.

Terminal, 기본 동사
claude plugin marketplace add <git URL 또는 마켓 이름>   # 마켓 등록
claude plugin install <플러그인>@<마켓>                  # 설치 (세션 재시작 필요)
/plugin                                                 # 세션 안 메뉴: list, enable, disable
/reload-plugins                                         # 재시작 없이 변경 반영

워크샵에서 쓰는 플러그인 3종

캡스톤 M0와 OPTION 하네스 엔지니어링에서 실제로 설치하고 사용합니다.

플러그인역할주요 커맨드워크샵 등장
superpowers@claude-plugins-official 브레인스토밍부터 실행까지의 구조화 개발 워크플로. 계획 승인 후 git worktree로 이동해 작업 /superpowers:brainstorming, /superpowers:write-plan, /superpowers:execute-plan 캡스톤 M0
project-init@project-init
github.com/whchoi98/project-init		 하네스 스캐폴딩 자동화. 기존 프로젝트 감지 모드로 CLAUDE.md, 훅, 스킬, 테스트 골격 중 없는 것만 생성하고 문서 품질을 0-100 점수로 동기화 /project-init:init-project, /project-init:sync-docs, /health-check, /add-adr, /add-runbook OPTION 하네스
harness-eval@harness-eval
github.com/whchoi98/harness-eval		 하네스 품질을 6개 차원(정확성, 안전성, 완전성, 실행 가능성, 일관성, 검증 가능성)에서 A+~F로 채점. quick 30초, standard 2~3분, full 5~10분 /harness-eval:quick, :standard, :full, :compare OPTION 하네스
신뢰 가드 harness-eval의 standard 이상은 대상 프로젝트의 훅과 테스트를 실제 실행합니다. 본인 프로젝트는 안전하지만 남의 저장소를 평가할 때는 --static-only가 예의이자 안전입니다. 서드파티 마켓의 플러그인은 설치 전 저장소를 한 번 읽어 보는 습관을 권합니다.

기타 추천 플러그인

공식 마켓(claude-plugins-official)은 Claude Code 시작 시 자동 등록되어 있어 marketplace add 없이 바로 install됩니다. 크게 세 갈래입니다: LSP 코드 인텔리전스, 내부 워크플로 도구, 외부 서비스 연동.

플러그인 / 계열역할설치
github@claude-plugins-official 공식 GitHub MCP 서버. 이슈 생성, PR 관리와 리뷰, 저장소 검색을 세션 안에서 직접 /plugin install github@claude-plugins-official
LSP 계열 (예: pyright-lsp) 언어 서버를 물려 정의 이동, 참조 찾기, 편집 직후 타입 오류 확인. VS Code 인텔리전스와 같은 기술. 해당 언어 서버 바이너리가 시스템에 필요 /plugin 목록에서 사용 언어의 LSP 선택
42crunch-api-security-testing OpenAPI 스펙 자동 감사와 OWASP API 리스크(BOLA/BFLA 포함) 탐지, AI 수정 제안 /plugin install 42crunch-api-security-testing@claude-plugins-official
외부 서비스 연동 계열 웹 크롤링/검색, DB, 협업 도구 등 파트너 MCP 묶음. 자격증명은 각 서비스에서 발급 /plugin에서 서비스명으로 검색
두 번째 마켓, 커뮤니티 공식 마켓과 별도로 보안 스캔을 거친 커뮤니티 마켓이 있습니다. 등록과 설치는 두 줄입니다: claude plugin marketplace add anthropics/claude-plugins-community 후 claude plugin install 이름@claude-community. 마켓 add는 owner/repo 축약형과 임의 Git URL, 로컬 경로를 모두 받으므로, 팀 전용 사내 마켓을 만들어 배포하는 것도 같은 문법입니다.

더 찾아보기

전체 라인업은 세션에서 /plugin을 열거나 github.com/anthropics/claude-plugins-official 저장소에서 확인하는 것이 가장 정확합니다. 설치한 플러그인의 스킬과 커맨드는 설치 직후 새 세션부터 슬래시 목록에 합류합니다.
