SETUP 01

Claude HUD, 세션 계기판

5분

상태줄에 토큰 사용량, 활성 에이전트, 투두, 깃 상태를 상시 표시하는 HUD 플러그인입니다. 캡스톤처럼 긴 빌드에서 컨텍스트가 얼마나 남았는지 감으로가 아니라 눈으로 봅니다. 원본: github.com/jarrodwatts/claude-hud

1설치와 설정, 순서대로 한 줄씩

Claude 세션 안에서 다섯 줄이면 끝납니다. 순서가 중요합니다: 마켓 등록 → 설치 → 리로드 → 표시 항목 설정 → 상태줄 활성화. 마지막 setup까지 마쳐야 하단 바가 나타납니다.

Claude 세션 입력 1/5
/plugin marketplace add jarrodwatts/claude-hud
Claude 세션 입력 2/5
/plugin install claude-hud
Claude 세션 입력 3/5
/reload-plugins

/reload-plugins로 설치를 세션에 반영한 뒤 설정 커맨드가 열립니다.

Claude 세션 입력 4/5
/claude-hud:configure

/claude-hud:configure는 상태줄에 무엇을 띄울지(토큰, 도구, 스킬, 에이전트, 깃 상태 등) 대화형으로 고르는 단계입니다. 고민되면 프리셋 Full로 전부 켜 두고, 나중에 같은 커맨드로 다시 조정하면 됩니다. 스킬, 도구, 에이전트 표시는 기본 숨김이라 여기서 켜야 하며, 해당 활동이 있을 때만 바에 나타납니다.

Claude 세션 입력 5/5
/claude-hud:setup
하단 바가 안 보인다면 다섯 줄의 순서를 지켰는지 먼저 확인하세요, 특히 리로드 전에 configure를 치면 커맨드가 없다고 나옵니다. 그래도 조용하면 /exit로 나갔다가 claude로 재진입하면 상태줄이 뜹니다.

SETUP 03

Agent Toolkit for AWS

3분

캡스톤의 CDK 배포, Lambda 작업, 데이터 파이프라인에서 Claude에게 AWS 지식과 안전 가드를 쥐여 주는 툴킷 6종입니다. 역할을 훑고 터미널 루프로 일괄 설치합니다.

플러그인역할
aws-core공통 기반. 최신 AWS 문서와 검증된 절차, IAM 가드레일을 세션에 공급, 나머지 다섯의 토대
aws-agentsBedrock 기반 에이전트 설계와 배포(AgentCore 계열) 작업 지원
aws-data-analytics데이터 파이프라인과 분석 스택(수집, 카탈로그, 쿼리) 작업 지원
aws-agents-for-devsecops보안과 컴플라이언스 관점의 점검, DevSecOps 워크플로 지원
databases-on-awsRDS, DynamoDB 등 데이터베이스 설계와 운영 작업 지원
aws-serverlessLambda, API Gateway 등 서버리스 개발과 배포 지원. 캡스톤의 Lambda 작업과 직결

정확한 커맨드와 범위는 설치 후 /plugin 목록의 설명에서 확인하세요.

1일괄 설치, 터미널 루프
Terminal, 전체 복사
for p in aws-core aws-agents aws-data-analytics aws-agents-for-devsecops databases-on-aws aws-serverless; do
  claude plugin install "$p@claude-plugins-official"
done

Terminal, 전체 복사
for p in frontend-design code-review context7 code-simplifier github playwright claude-md-management feature-dev security-guidance typescript-lsp vercel ralph-loop claude-code-setup commit-commands figma supabase pr-review-toolkit pyright-lsp chrome-devtools-mcp serena slack plugin-dev agent-sdk-dev explanatory-output-style playground hookify linear remember microsoft-docs data-engineering deploy-on-aws terraform; do
  claude plugin install "$p@claude-plugins-official"
done
많이 깔수록 공짜가 아닙니다 Chapter 4에서 본 것처럼 플러그인의 도구와 스킬 설명은 세션 컨텍스트에 로드됩니다. 설치 후 /context all로 비용을 확인하고, 당장 안 쓰는 것은 /plugin에서 disable해 두는 것이 캡스톤 컨텍스트 관리의 정석입니다. 개별 플러그인의 정확한 역할은 /plugin 목록의 설명으로 확인하세요.

+보너스, 실시간 웹 검색 붙이기

이 워크샵 환경에는 Amazon Bedrock AgentCore Gateway의 Web Search 도구가 미리 배포되어 있습니다. 아래 명령 하나로 MCP 서버로 등록됩니다 - 게이트웨이 주소 조회부터 등록까지 스크립트가 알아서 처리하므로 인자가 필요 없습니다. 캡스톤 리서치(최신 서비스 발표, 라이브러리 문서 이후의 변경 사항)에서 바로 씁니다.

Terminal
use_websearch

등록 후 claude에서 /mcp에 agentcore-web-search ✔ connected가 보이면 완료 - "최근 AWS 신규 서비스 발표 알려줘"처럼 최신 정보 질문을 던지면 실제 웹 출처(URL, 발행일)가 인용됩니다. 쿼리는 AWS 밖으로 나가지 않습니다(Amazon 자체 웹 인덱스). "게이트웨이가 준비되지 않았습니다"가 나오면 이 환경에선 미제공이니 그대로 진행하세요.
