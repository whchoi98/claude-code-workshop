REFERENCE 2 / SLASH COMMANDS

슬래시 커맨드, 세션을 조종하는 레버들

문법 규칙, 그룹별 상세 기능, 인자와 별칭, 워크샵 등장 위치

세션 안에서 /로 시작하는 커맨드는 모델 전환부터 병렬 실행, 리뷰, 세션 이동까지 Claude Code를 조종하는 레버입니다. 실무에서 손이 자주 가는 것들을 워크플로 순서로 묶고, 인자와 별칭, 알아 두면 좋은 세부 동작까지 담았습니다.

커맨드 문법, 30초 규칙

표를 읽기 전에 알아 둘 동작 규칙입니다.

규칙내용
위치커맨드는 메시지 맨 앞에서만 인식되고, 뒤에 오는 텍스트는 그 커맨드의 인자가 됩니다.
큐잉Claude가 응답 중일 때 보낸 커맨드는 현재 턴이 끝난 뒤 실행됩니다. 단 /status, /tasks, /usage처럼 조회성 커맨드는 즉시 실행됩니다.
스킬 체이닝스킬 호출은 예외적으로 여러 개를 이어 쓸 수 있습니다: /skill-a /skill-b 지시문 형태로 최대 6개까지, 뒤 텍스트가 각 스킬의 인자로 전달됩니다 (v2.1.199+).
표기아래 표에서 <인자>는 필수, [인자]는 선택입니다. SKILL은 내장 스킬(프롬프트를 Claude가 수행), WORKFLOW는 다수 서브에이전트를 부채꼴로 펼치는 백그라운드 워크플로입니다.

시작과 설정

새 저장소에서의 첫 세션, 그리고 세션의 뼈대를 잡는 커맨드.

커맨드하는 일워크샵
/init프로젝트를 훑어 시작용 CLAUDE.md 생성. 환경변수 CLAUDE_CODE_NEW_INIT=1이면 스킬, 훅, 개인 메모리까지 함께 잡아 주는 대화형 온보딩으로 동작Ch1
/memoryCLAUDE.md 메모리 파일 편집, 자동 메모리(auto-memory) 켜고 끄기와 항목 열람Ch1
/config [key=value ...]
별칭 /settings		설정 화면. key=value를 붙이면 화면 없이 즉시 변경(/config thinking=false, /config model=sonnet). /config --help가 설정 가능한 전체 키를 출력-
/model [모델]모델 전환과 기본값 저장. 피커에서 s를 누르면 이 세션만 전환. 대화 이력이 있으면 캐시 재구축 비용을 확인 후 적용Ch1
/effort [레벨]추론 강도. low, medium, high, xhigh에 세션 한정 max까지, 가용 레벨은 모델별. 인자 없이 실행하면 좌우 화살표 슬라이더-
/permissions
별칭 /allowed-tools		도구 allow, ask, deny 규칙을 스코프별로 열람/추가/삭제. 작업 디렉토리 관리와 자동 모드 거부 이력 검토 포함Ch3
/mcp [reconnect|enable|disable]MCP 서버 연결과 OAuth 관리. reconnect 서버명으로 재접속, enable/disable에 서버명이나 allCh4
/plugin [서브커맨드]플러그인 메뉴. list, install, enable, disable을 직접 지정 가능 (market은 marketplace 축약)Ch4, 캡스톤 M0
/hooks도구 이벤트에 걸린 훅 구성 확인. 훅 자체는 각 스코프 settings.json의 hooks 블록에 정의Ch4
/agents서브에이전트 안내. 최신 버전은 .claude/agents/ 또는 ~/.claude/agents/ 직접 편집을 권장Ch2

작업 흐름

한 세션 안에서 컨텍스트와 페이스를 다루는 커맨드.

커맨드하는 일워크샵
/plan [설명]플랜 모드 진입. 설명을 붙이면 그 작업 계획으로 즉시 시작 (/plan 인증 버그 수정)-
/compact [지침]대화를 요약해 컨텍스트 확보. 요약 초점 지침 전달 가능. 규칙과 스킬, 메모리는 요약을 살아남음Ch5
/context [all]컨텍스트 사용량을 색 격자로 시각화하고 무거운 도구, 메모리 비대, 용량 경고와 최적화 제안. all로 상세 펼침-
/clear [이름]
별칭 /new, /reset		빈 컨텍스트로 새 대화. 이름을 주면 직전 대화가 /resume 목록에 그 라벨로 남음. 되감기 메뉴로 복구도 가능Ch1
/btw [질문]대화 기록에 남지 않는 곁다리 질문. 인자 없이 실행하면 이 세션의 지난 곁다리 답들을 다시 열람-
/goal [조건|clear]조건을 걸면 달성까지 턴을 이어서 작업. clear, stop 등으로 조기 해제-
SKILL/loop [주기] [프롬프트]
별칭 /proactive		프롬프트를 주기 반복 실행 (/loop 5m 배포 끝났는지 확인). 프롬프트 생략 시 .claude/loop.md 또는 자율 점검-
/copy [N]마지막(또는 N번째 최근) 응답을 클립보드로. 코드 블록이 있으면 피커 제공, w 키로 파일 저장(SSH에서 유용)-
/diff미커밋 변경과 턴별 변경의 대화형 뷰어. 좌우로 git diff와 턴 전환, 상하로 파일 탐색, Enter로 상세-

병렬과 백그라운드

Chapter 2의 서브에이전트 감각이 세션 단위로 확장된 영역.

커맨드하는 일워크샵
/tasks현재 세션의 백그라운드 작업과 완료된 서브에이전트 목록. 응답 중에도 즉시 실행되는 조회 커맨드-
/background [프롬프트]
별칭 /bg		세션을 백그라운드 에이전트로 분리해 터미널 해방. 분리 전 마지막 지시 전달 가능, claude agents로 모니터-
/fork [프롬프트]지금까지의 대화를 복사해 별도 백그라운드 세션으로. 프롬프트를 주면 복사본이 즉시 작업 시작-
/branch [이름]현재 지점에서 대화를 분기해 다른 방향 시도. 원본은 보존되어 /resume으로 복귀-
SKILL/batch <지시>대규모 변경을 5~30개 독립 단위로 분해해 승인 후 단위별 worktree에서 병렬 구현, 테스트, PR까지. git 저장소 필요-

검수와 리뷰

출하 직전의 관문. Chapter 5 리뷰 봇의 내장판.

커맨드하는 일워크샵
SKILL/code-review [레벨] [--fix] [대상]현재 diff의 정확성 리뷰. 레벨 low~max, --fix로 자동 반영, --comment로 GitHub 인라인 코멘트, ultra는 클라우드 다중 에이전트 심층Ch5 연계
/review [PR]GitHub PR을 읽기 전용 단일 패스로 빠르게 리뷰-
/security-review현재 diff의 보안 취약점 점검-
SKILL/verify변경이 의도대로인지 검증하는 내장 스킬. 명시 호출 시에만 동작-
/export [파일명]대화를 텍스트로 내보내기. 파일명을 주면 바로 저장, 없으면 클립보드/파일 선택-

세션 이동과 복구

세션을 시간과 기기 너머로 옮기는 커맨드.

커맨드하는 일워크샵
/resume이전 대화로 복귀. 헤드리스 --resume의 대화형 짝Ch5
/rewind코드와 대화를 체크포인트로 되감기, 또는 구간 요약. /clear 이전 대화도 항목으로 복구 가능-
/cd <경로>세션을 다른 디렉토리로 이사. 캐시를 보존하고 세션 저장소도 함께 옮겨 그 폴더에서 --resume 가능. 접근만 열려면 /add-dir-
/teleportclaude.ai 웹 세션을 이 터미널로 가져오기-
/remote-control이 로컬 세션을 다른 기기(claude.ai)에서 이어서 조작-

상태와 도움

점검, 비용, 그리고 문제가 생겼을 때.

커맨드하는 일워크샵
/status인증, 모델, 컨텍스트, 설정 출처를 한눈에. 즉시 실행 커맨드Ch1
/usage
별칭 /cost		사용량과 비용-
SKILL/doctor
별칭 /checkup		설치/설정 건강검진과 수리 제안: 중복 설치, PATH, 깨진 설정, 미사용 스킬/MCP/플러그인의 컨텍스트 비용, 느린 훅, CLAUDE.md 다이어트까지. 변경 전 항상 확인을 받음-
SKILL/debug [설명]이 세션의 디버그 로깅을 켜고 로그를 읽어 문제 진단-
/help사용 가능한 전체 커맨드 목록-
/release-notes버전별 변경 사항 뷰어-
/feedback [내용]
별칭 /bug		버그 리포트와 피드백. 포함 범위를 선택하고 동의 화면을 거쳐 전송, 서드파티 연결에선 로컬 번들로 저장-
/login / /logoutAnthropic 계정 로그인과 로그아웃Ch1
/exit
별칭 /quit		CLI 종료. 접속해 있던 백그라운드 세션이라면 분리만 되고 세션은 계속 실행-

확장과 유지보수

스킬과 플러그인, 통합을 관리하는 커맨드.

커맨드하는 일워크샵
/reload-skills디스크에서 추가/변경된 스킬을 재스캔해 재시작 없이 반영 (v2.1.152+)Ch4
/reload-plugins [--force]플러그인 변경 반영. MCP 도구 구성이 바뀌어 캐시가 무효화될 상황이면 경고 후 --force 요구-
SKILL/fewer-permission-prompts지난 기록에서 자주 승인한 읽기 전용 명령을 찾아 프로젝트 설정에 허용 목록으로 제안-
/install-github-app저장소에 Claude GitHub App 설치, Actions 워크플로와 시크릿 구성까지 안내Ch5 연계
WORKFLOW/deep-research <질문>웹 검색을 부채꼴로 펼쳐 교차 검증하고 출처 있는 리포트로 종합-
/insights내 세션들을 분석해 작업 영역, 사용 패턴, 마찰 지점 리포트 생성-
커스텀 커맨드는 스킬로 직접 만드는 슬래시 커맨드는 이제 .claude/skills/이름/SKILL.md가 표준입니다. 구식 .claude/commands/*.md도 아직 동작하지만 legacy로 분류됩니다 (Chapter 4에서 실습). 목록은 버전, 플랜, 플랫폼에 따라 다르니 세션에서 /만 입력해 실제 목록을 확인하세요. 예를 들어 Bedrock 연결에서는 claude.ai에 닿아야 하는 일부 커맨드가 비활성입니다.
