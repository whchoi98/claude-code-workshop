Claude Code Deep Dive Workshop

Hands-on Lab 포털 - Chapter 1~5 정규 랩 + Capstone Mission 4종

이틀 동안 Claude Code를 설치하고, 자동화와 서비스 개발에 활용하는 방법을 실습합니다. 모든 랩은 독립 HTML 문서로, 아래에서 열어 진행 상황을 체크하며 따라갑니다. 캡스톤은 네 가지 미션 중 하나를 선택해 완주하며, 별도 인프라 없이 혼자서도 처음부터 끝까지 수행할 수 있습니다.

구성 준비 2 + Chapter 랩 6 + Capstone 4 + Reference 3 환경 Claude Code on EC2 + Admin 계정 리전 ap-northeast-2 모델 Opus 5.8, Sonnet 5.0, Sonnet 4.6 (Global CRIS) Update 2026.09

Claude Code, 설치부터 Headless 자동화까지

Subagents, 전문 에이전트를 만들고 지휘하기

 40분 내외준비 + 5 Task 랩 열기 → CH 03

Admin Setup, 통제 가능한 Enterprise 배포

관리자의 40분. managed settings와 정책 배포, Bedrock 라우팅, 조직 단위 통제선 구축.

 40분 내외준비 + 5 Task 랩 열기 → CH 04

 60분 내외준비 + 4 Task 랩 열기 →

Capstone Missions

이틀 2라운드 / Day 1 택 1 + Day 2 택 1

이틀 동안 두 번 완결합니다. Day 1 라운드 1은 게임, 미술관(로컬 완결) 또는 2시간 트랙 지진 워치(CloudFront 실배포) 중 택 1. Day 2 라운드 2는 풀 트랙 증시, 유튜브(깊이 우선) 또는 2시간 트랙 뉴스룸 렌즈(키 발급 없음, CloudFront 실배포까지) 중 택 1입니다. 난이도가 아니라 정체성이 다르니 관심사에 맞춰 고르세요. 전부 superpowers의 brainstorm → plan → execute 워크플로로 진행합니다.

SETUP

Capstone 시작 전, 설치하면 좋은 것들

Claude HUD 계기판, superpowers, Agent Toolkit for AWS 6종, 풀 스택 플러그인 32종 일괄 설치.

 15분단계 4개 열기 →
MISSION 1 Press Start

Clawd Jump, 에이전틱 게임 개발

Day 1, 라운드 1. Claude Code 마스코트 Clawd의 슈퍼마리오풍 플랫포머를 만듭니다. superpowers로 엔진, 물리 동작, 타일 레벨, 코인과 깃발을 모두 구현하고 CloudFront로 배포합니다. Bedrock을 사용하지 않으며, API 키는 필요하지 않습니다.

피날레: 내가 만든 게임 URL을 Slack에 공유하고 서로 플레이합니다.

135분 / 미션 5 + DoD시작 → MISSION 2 Market Desk

웹 시황 대시보드

Day 2, 라운드 2. FastAPI + React + lightweight-charts로 지표 바, 지수 카드, 종목 테이블, 캔들 차트를 구현합니다. Bedrock의 종목 분석은 SSE로 타자기처럼 표시됩니다. 캐시는 single-flight 방식으로 구성하고, make run 하나로 실행합니다. 원작 stock-monitoring을 축소한 실습입니다.

피날레: 브라우저에서 실행 중인 내 대시보드의 스크린샷을 Slack에 공유합니다.

135분 / 미션 5 + DoD시작 → MISSION 3 Frame It

Generative Hours, 코드로 그린 전시를 배포하라

Day 1, 라운드 1. 제너러티브 아트 두 점으로 인터랙티브 미디어 아트 전시를 만듭니다. 첫 작품은 추상화 없이 완성하고, 두 번째 작품을 추가할 때 공통 계약을 추출합니다. 추상화가 생겨나는 순간을 직접 경험하는 실습입니다. Bedrock을 사용하지 않으며, API 키는 필요하지 않습니다.

피날레: 내 전시 URL을 Slack에 공유하고 서로 관람합니다.

120분 / 미션 6 + DoD시작 → MISSION 4 Trend Radar

유튜브 급상승 30, 트렌드 레이더

Day 2, 라운드 2. 급상승 30을 주기적으로 수집해 스냅샷으로 쌓고, 순위 변동(▲▼)과 NEW, 카테고리 점유율의 변화를 확인합니다. 브리핑 기능은 SDK 없이 REST로 Bedrock을 직접 호출하며, now/daily 두 모드를 제공합니다. 원작 youtube-trend를 축소한 실습입니다.

피날레: 흐름이 읽히는 레이더 스크린샷을 Slack에 공유합니다.

135분 / 미션 5 + DoD시작 → MISSION 5 Quake Watch

지구의 맥박, 실시간 지진 워치

Day 1, 라운드 1 (2시간 트랙). USGS 실시간 피드를 멱등하게 수집해 진앙을 세계지도 SVG에 펄스로 표시합니다. Bedrock이 "지난 24시간, 지구는"을 절제된 한국어로 해설합니다. 키 발급 없이 진행하며, CloudFront에 실제로 배포합니다.

피날레: 누구나 열어 볼 수 있는 내 지진 워치 URL을 Slack에 공유합니다.

120분 / 미션 5 + DoD시작 → MISSION 6 Newsroom Lens

뉴스룸 렌즈, 4개 매체 관점 비교

Day 2, 라운드 2 (2시간 트랙). BBC, Guardian, NHK, 연합뉴스의 RSS를 수집해 공통 토픽으로 묶고, 매체별 프레임을 한국어로 나란히 비교합니다. LLM 출력은 JSON 계약에 맞춰 화면에 표시합니다. 요약을 넘어 보도 관점의 차이를 살펴보는 도구입니다.

피날레: 내 미디어 렌즈 URL을 Slack에 공유합니다.
