# 현황판 (HTML)

요청: $ARGUMENTS

요청이 비어 있으면 강남역, 여의도, 성수카페거리 세 곳을 비교한다.

현황판은 자료 파일(JSON) 하나로 만든다. 화면 틀과 움직임은 정해져 있으므로 HTML을 직접 쓰거나 고치지 않는다. 할 일은 자료를 모아 자료 파일을 쓰고 도구를 실행하는 것이다.

## 순서

1. `${CLAUDE_SKILL_DIR}/../../kit/data-guide.md`를 읽는다. 자료를 어디서 가져오고 숫자를 어떻게 다루는지 적혀 있다.
2. 자료를 모은다.
   - 장소 비교라면 장소마다 `get_city_snapshot`을 한 번씩 부른다. 이름이 모호하면 `search_place`로 정식 이름을 먼저 찾는다.
   - 카드에 더 넣을 값이 필요하면 `get_road_traffic`, `get_weather`, `get_parking`, `get_bike_stations`, `get_commercial_activity` 가운데 필요한 것만 부른다.
   - 사용자가 CSV나 표를 주면 그 파일을 읽어 같은 모양으로 옮긴다.
3. 자료 파일을 `work/<짧은-영문-이름>.json`에 쓴다. 모양은 아래 "자료 모양"과 예시를 따른다. Write 도구로 직접 쓰고, 셸이나 python으로 만들어 쓰지 않는다.
4. 만든다.
   ```bash
   python3 "${CLAUDE_SKILL_DIR}/../../kit/kit.py" board work/<이름>.json
   ```
   명령은 위 모양 그대로 하나씩 실행한다. 경로를 변수에 담거나 `&&`, `;`로 여러 명령을 묶으면 사용자에게 승인 창이 뜬다.
   `[검사 실패]`가 나오면 알려 준 칸의 값만 고쳐 다시 실행한다. 규칙을 바꾸거나 도구를 고치지 않는다.
5. 사용자에게 알린다. 결과 보관함 주소(도구가 출력한 안내), 기준 시각, 숫자의 출처, 바꿔 볼 만한 것 두 가지를 짧게 적는다.

## 자료 모양

정확한 규칙은 `python3 "${CLAUDE_SKILL_DIR}/../../kit/kit.py" rules board`, 완성된 예시는 `... kit.py example board`로 본다.

| 항목 | 내용 |
|---|---|
| `title`, `subtitle` | 제목 30자, 부제 50자 이하 |
| `asOf` | 기준 시각. 도구 응답의 `asOf`를 옮기고 "기준"을 붙인다 |
| `cards` | 2~6장. `label`, `value`(숫자), `unit`, `decimals`, `signal`, `note` |
| `table` | `caption`, `columns`(2~7열, `type`은 text 또는 number, `bar`는 막대 표시), `rows`(2~15줄) |
| `insights` | 읽어 낸 것 1~3줄. 줄마다 60자 이하 |
| `sources` | 출처 1~6개. `name`, `detail`, `url` |
| `legend` | 신호등 이름을 바꿀 때만. 예: 달성, 주의, 미달 |

- `value`와 number 열의 값은 따옴표 없는 숫자로 쓴다. 쉼표와 단위는 화면이 붙인다.
- `signal`은 `green`, `yellow`, `red`, `none`. 정하는 기준은 data-guide.md 5번을 따른다.
- 카드에는 가장 눈에 띄는 값을, 표에는 비교할 전체를 넣는다. 카드와 표가 같은 내용을 되풀이하지 않게 한다.

## 사용자가 고쳐 달라고 하면

`work/`의 자료 파일을 고치고 같은 명령을 다시 실행한다. 새 숫자가 필요할 때만 도구를 다시 부른다. 완성된 화면에서 P를 누르면 발표 모드가 되고, 표 머리글을 누르면 정렬된다는 것을 알려 준다.
