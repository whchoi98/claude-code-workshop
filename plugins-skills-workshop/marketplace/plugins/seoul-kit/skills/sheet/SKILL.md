# 통계표 (Excel)

요청: $ARGUMENTS

요청이 비어 있으면 강남역 2호선의 시간대별 승하차 통계표를 만든다.

통계표는 자료 파일(JSON) 하나로 만든다. 원자료 숫자만 적고 합계와 비율과 순위는 Excel 수식 열로 남긴다. 받은 사람이 Excel에서 값을 고치면 계산이 따라 바뀌어야 하기 때문이다.

## 순서

1. `${CLAUDE_SKILL_DIR}/../../kit/data-guide.md`를 읽는다.
2. 자료를 모은다. 통계표에 잘 맞는 자료는 다음과 같다.

   | 주제 | 도구 | 표 모양 |
   |---|---|---|
   | 지하철 시간대별 승하차 | `get_subway_hourly_ridership` | 시간대마다 한 줄. 승차, 하차 |
   | 자치구별 대기질 | `get_air_quality` | 자치구마다 한 줄. 미세먼지, 초미세먼지 |
   | 부동산 실거래 | `get_real_estate_prices` | 거래마다 한 줄. 동, 건물, 면적, 금액(만원) |
   | 문화행사 | `search_cultural_events` | 행사마다 한 줄. 분류, 기간, 장소 |
   | 내 자료 | 사용자가 준 CSV나 표 | 받은 모양 그대로 |

   비교할 기준이 서울 MCP에 없으면 웹에서 찾아 시트를 하나 더 만든다.
3. 자료 파일을 `work/<짧은-영문-이름>.json`에 쓴다. Write 도구로 직접 쓰고 셸이나 python으로 만들어 쓰지 않는다.
4. 만든다.
   ```bash
   python3 "${CLAUDE_SKILL_DIR}/../../kit/kit.py" sheet work/<이름>.json
   ```
   명령은 위 모양 그대로 하나씩 실행한다. 경로를 변수에 담거나 `&&`, `;`, `|`로 여러 명령을 묶으면 사용자에게 승인 창이 뜬다. 출력이 길어도 `head`나 `sed`를 붙여 자르지 않는다.
   `[검사 실패]`가 나오면 알려 준 칸만 고쳐 다시 실행한다.
5. 사용자에게 알린다. 결과 보관함에서 내려받는다는 것, 시트 구성, 어떤 수식을 넣었는지, 출처를 짧게 적는다. Excel에서 노란 띠가 보이면 "편집 사용"을 눌러야 수식이 계산된다는 것도 알려 준다.

## 자료 모양

정확한 규칙은 `python3 "${CLAUDE_SKILL_DIR}/../../kit/kit.py" rules sheet`, 완성된 예시는 `... kit.py example sheet`로 본다.

- `title`, `subtitle`, `asOf`, `sheets`(1~4개), `sources`. `asOf`는 30자 이하다. 기준 시각이 여럿이면 가장 이른 시각과 가장 늦은 시각만 적는다.
- 시트마다 `name`, `columns`(2~12열), `rows`(1~200줄), `chart`(없어도 됨), `notes`(없어도 됨, 3줄까지이고 줄마다 80자 이하).
- 열의 `type`은 `text`, `number`, `formula` 가운데 하나다.
  - `format`: `int`, `decimal1`, `decimal2`, `percent`, `won`, `text`
  - `total`: 표 아래 요약 줄. `sum`, `average`, `max`, `min`
  - `visual`: `scale`(색 눈금), `bar`(칸 안의 막대)
- `rows`에는 수식 열을 뺀 나머지 열의 값만 순서대로 적는다.

## 수식 열

`formula`는 `=`로 시작한다. `[열 이름]`은 같은 줄의 칸, `[열 이름:전체]`는 그 열 전체를 가리킨다.

| 하고 싶은 것 | formula | format |
|---|---|---|
| 두 열 더하기 | `=[승차]+[하차]` | int |
| 전체에서 차지하는 비중 | `=[합계]/SUM([합계:전체])` | percent |
| 순위 | `=RANK([합계],[합계:전체])` | int |
| 평당 가격처럼 나누기 | `=ROUND([금액]/[면적],0)` | int |

쓸 수 있는 함수는 SUM, AVERAGE, MAX, MIN, ROUND, IF, RANK, ABS, COUNT뿐이다. 다른 파일이나 웹을 부르는 수식은 넣을 수 없다.

## 좋은 통계표

- 첫 열은 줄의 이름(시간대, 자치구, 건물)으로 둔다.
- 비교하려는 열 하나에 `visual`을 주고 같은 색 눈금을 모든 열에 칠하지 않는다.
- 차트는 표 하나에 하나만 둔다. 흐름은 `line`, 크기 비교는 `column`이나 `bar`가 맞다.
- 단위와 기간, 값의 뜻(월 합계인지 하루 값인지)을 `notes`에 적는다.
