# 서울 데이터 실습 작업 폴더

Claude Code 워크숍 Day 1 실습용 폴더다. 사용하는 사람은 개발자가 아닐 수 있다.

## 말하는 법

- 한국어로, 쉬운 말로 답한다. 명령어와 파일 구조 설명은 꼭 필요할 때만 한 줄로 한다.
- 결과를 먼저 말한다. 무엇을 만들었고 어디서 열어 보는지, 숫자가 어디서 왔는지를 알려 준다.
- 숫자를 지어내지 않는다. 확인하지 못한 값은 확인하지 못했다고 말한다.

## 폴더

- `work/`: 산출물의 자료 파일(JSON). 고칠 때는 이 파일을 고친다.
- `out/`: 만들어진 현황판(HTML), 통계표(Excel), 브리핑(PowerPoint)과 결과 보관함.
- `data/seoul-sample/`: 서울 MCP가 응답하지 않을 때 쓰는, 미리 받아 둔 응답.
- `data/team-kpi.csv`: "내 업무로 바꾸기" 미션에 쓰는 연습용 팀 지표(지어낸 예시 숫자).

## 파일과 명령

- 파일을 만들거나 고칠 때는 Write나 Edit 도구를 쓴다. `echo`, `sed`, `cat` 같은 셸 명령으로 파일에 쓰지 않는다. CSV에 줄을 더할 때도 같다.
- 파일 내용은 Read 도구로 읽는다.
- 셸 명령이 꼭 필요하면 한 번에 하나만 실행한다. `&&`, `;`, `|`로 묶거나 앞에 `cd`를 붙이면 사용자에게 승인 창이 뜬다.

## 도구

- 서울 데이터는 `seoul` MCP 서버에서 가져온다. 없는 자료는 WebSearch와 WebFetch로 보강하고 출처를 적는다.
- 산출물은 seoul-kit 플러그인의 Skill로 만든다: `/seoul-kit:board`, `/seoul-kit:sheet`, `/seoul-kit:deck`.
- 결과는 브라우저에서 code-server 주소 끝에 `/proxy/8000/`을 붙여 연다.
